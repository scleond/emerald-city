On this Windows host, GitHub CLI authentication is stored in the normal user's Windows keyring. Codex sandbox commands run under a separate account and may misleadingly report an invalid token. For authorized GitHub CLI operations and Git operations requiring remote authentication, request execution outside the sandbox using the normal approval mechanism and narrowly scoped commands. Do not reauthenticate, export credentials, or change credential storage based solely on a sandbox authentication failure. If approval is denied, report the denial.
