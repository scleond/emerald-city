# STE-Style Writing

Rewrite or author text as **STE-style** — a practical, simplified technical
English in the spirit of ASD-STE100: one clear meaning per sentence, short
procedural steps, active voice, and consistent terminology. This is *STE-style*,
not formally ASD-STE100 certified; do not claim certification.

## When to use

Trigger on an explicit request for ASD-STE100 / STE / simplified technical
English, or when repository instructions call for controlled English.

## Vocabulary source

- Use a repository glossary or `CONTEXT.md` when one is present.
- Otherwise create a task-local term list: one term per concept. Pick the term
  and the one sense it is used in, and hold it steady through the text.

## Write pass

Rewrite the source text:

- One meaning per sentence.
- Active voice where practical; make the subject explicit.
- Explicit references — avoid ambiguous `it` / `this` / `that`.
- Consistent terminology — do not rename a concept mid-text.
- Short procedural steps, each a single action.
- No decorative wording; delete fluff and redundancy.

Keep the meaning of the source. When the source is ambiguous, pick the most
literal reading, note it, and keep the chosen meaning consistent.

## Final pass

Check every sentence against the list above. Confirm the term list covers every
concept and each term names one concept. Report the result as *STE-style*, not
formally certified.
